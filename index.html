تطبيق لمح يتيح للمسافر إنشاء رحلة وتحديد وزن الحمل، وللمرسل طلب شحنة مع هذا المسافر. توضّح هذه السياسة البيانات التي نجمعها وكيف نستخدمها.

المعلومات التي نقوم بجمعها

نقوم بجمع البيانات التالية:

  • البيانات الشخصية (الاسم، رقم الجوال، البريد الإلكتروني)
  • بيانات الحساب والرحلات وطلبات الشحن
  • بيانات الجهاز والاستخدام
  • بيانات مكان التسليم والاستلام لتسليم الشحنة بين الطرفين

استخدام البيانات

تُستخدم البيانات من أجل:

  • تقديم خدمة الربط بين المسافر والمرسل
  • إنشاء الرحلة وتحديد وزن الحمل وطلب الشحنة
  • التحقق من هوية المستخدم
  • إرسال الإشعارات والتنبيهات
  • تحسين أداء وأمان التطبيق

مشاركة البيانات

قد يتم مشاركة البيانات مع:

  • المسافر أو المرسل المرتبط بالرحلة أو الشحنة، بالقدر اللازم للاتفاق والتسليم
  • مزودي خدمة الرسائل (OTP) عند التحقق من رقم الجوال
  • مزودي الاستضافة وتشغيل التطبيق
  • الجهات الرسمية عند الطلب النظامي

ولا يتم بيع أو تأجير بيانات المستخدم لأي طرف ثالث.

حماية البيانات

  • تشفير البيانات أثناء النقل والتخزين قدر الإمكان
  • استخدام بروتوكولات أمان مناسبة لتشغيل التطبيق
  • مراجعات أمنية دورية

الاحتفاظ بالبيانات

  • يتم الاحتفاظ بالبيانات للمدة اللازمة فقط لتشغيل الخدمة والدعم والالتزامات النظامية
  • يمكن للمستخدم طلب حذف حسابه نهائيًا من التطبيق

حقوق المستخدم

يحق للمستخدم:

  • الوصول إلى بياناته
  • تعديل معلوماته
  • حذف حسابه
  • إيقاف الإشعارات غير الضرورية

ملفات تعريف الارتباط (Cookies)

قد يستخدم التطبيق تقنيات مشابهة لتحسين تجربة المستخدم وتحليل الأداء.

التعديلات على سياسة الخصوصية

سيتم إشعار المستخدمين بأي تعديل عبر:

  • إشعار داخل التطبيق
  • تحديث النص في صفحة سياسة الخصوصية

Lamh lets travelers create a trip and set a carry weight, and lets senders request a shipment with that traveler. This policy explains what we collect and how we use it.

Information we collect

We collect the following data:

  • Personal data (name, mobile number, email)
  • Account, trip, and shipment-request data
  • Device and usage data
  • Handover location details for delivery between the two parties

How we use data

We use data to:

  • Match travelers and senders
  • Create trips, set carry weight, and request shipments
  • Verify the user’s identity
  • Send notifications and alerts
  • Improve app performance and security

Sharing data

Data may be shared with:

  • The traveler or sender linked to a trip or shipment, as needed to agree and hand over the parcel
  • SMS providers (OTP) when verifying a mobile number
  • Hosting and app-operation providers
  • Official authorities when legally required

User data is not sold or rented to any third party.

Data protection

  • Encryption in transit and at rest where reasonably possible
  • Security protocols appropriate to running the app
  • Periodic security reviews

Data retention

  • Data is kept only as long as needed to run the service, provide support, and meet legal duties
  • The user may request permanent deletion of their account from the app

User rights

The user may:

  • Access their data
  • Update their information
  • Delete their account
  • Turn off non-essential notifications

Cookies

The app may use similar technologies to improve the user experience and analyze performance.

Changes to this privacy policy

Users will be notified of any change through:

  • An in-app notice
  • An update to the text on this privacy policy page
